# ⚽ Análisis de Datos – Liga Argentina 2025

## 📌 Descripción del proyecto
Este proyecto presenta un análisis de datos de la Liga Argentina 2025, con el objetivo de explorar el rendimiento de equipos y jugadores, identificar tendencias competitivas y visualizar métricas clave del torneo.

El análisis fue desarrollado en Tableau, priorizando la creación de dashboards interactivos y visualmente claros para facilitar la interpretación de los datos.

## 🎯 Objetivos
- Analizar el rendimiento de los equipos a lo largo del torneo
- Comparar estadísticas clave (puntos, goles, partidos ganados, etc.)
- Identificar tendencias y patrones de rendimiento
- Construir un dashboard interactivo para exploración de datos

## 🛠️ Herramientas utilizadas
- Tableau (visualización y dashboard)
- Excel (preparación y limpieza de datos)

## 📊 Proceso de análisis

### 1. Limpieza de datos
- Corrección de valores inconsistentes
- Estandarización de nombres de equipos
- Validación de métricas

### 2. Transformación
- Creación de métricas clave (puntos, diferencia de gol, rendimiento)
- Agrupación de datos por equipo y jornada
- Preparación para visualización

### 3. Visualización
- Creación de dashboards interactivos en Tableau
- Uso de filtros dinámicos
- Comparación visual entre equipos

## 📈 Principales insights
- Los equipos con mayor cantidad de goles no siempre lideran la tabla
- La consistencia en resultados tiene mayor impacto que picos de rendimiento
- Existe una clara diferencia entre los equipos de la parte alta y baja de la tabla

## 📂 Archivos del repositorio
